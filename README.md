# Danitieli Araujo — Psicóloga

Site profissional em desenvolvimento, com apresentação, trajetória, abordagem comportamental e contato pelo WhatsApp.

## GitHub Pages

Site estático, sem instalação ou compilação. Configure **Settings → Pages → Deploy from a branch → main → / (root)**.

## Arquivos

- `index.html`: conteúdo e estrutura.
- `styles.css`: estilos e adaptação ao celular.
- `script.js`: menu móvel e ano do rodapé.
- `.nojekyll`: publicação direta dos arquivos estáticos.

Para atualizar, edite os arquivos e envie as alterações para a branch `main`. O GitHub Pages republicará o site.

O espaço do retrato está reservado para a fotografia da profissional.
